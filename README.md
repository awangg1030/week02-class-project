Ohm's Law Calculator - Part A

This is a code that will calculate using the formula of Ohm's Law to calculate the current based on user input. The user would input voltage (V) and resistance (R). This programwill only calculate current, nothing else. 

Example:
Input: 12 4 
Output: 3 A

When there are invalid inputs or resistance <= 0, the code will return 
Invalid Input 

Compile using the -Wall -Wextra -pendatric and use bash test.sh to test. 

Debugging - I debugged the program by using invalid and valid inputs to make sure the logic is accurate. The acceptance test with test.sh was useful in this case.
